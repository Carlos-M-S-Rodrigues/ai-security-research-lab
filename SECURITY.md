# Security Policy

## Responsible Disclosure

If you discover a vulnerability in this repository or in any published laboratory, please report it responsibly.

Do not publicly disclose vulnerabilities before they have been reviewed.

---

## Scope

This repository is intended exclusively for educational and research purposes.

The experiments documented here are designed to improve the understanding of AI Security concepts.

They must never be used to perform unauthorized activities against systems or services.

---

## Research Ethics

Every laboratory follows responsible security research principles.

The objective is to understand vulnerabilities in order to improve defensive capabilities.

---

## Contact

Security issues may be reported through GitHub Issues or by contacting the repository owner.
