# LAB-001 — AI Security Research Platform

## Status

✅ Completed — local AI Security platform deployed, validated and
documented.

## Objective

LAB-001 established the technical foundation for the AI Security
Research Lab.

The objective was to build a local and reproducible environment where
Large Language Models, prompts, APIs and future security experiments
could be executed without depending on external AI services.

## Platform Components

The laboratory was built using:

- Ubuntu 24.04 LTS
- Docker
- Docker Compose
- Ollama
- Open WebUI
- Llama 3
- Local API access
- Git and GitHub

## Architecture

The platform separates the user interface, model runtime, local model
storage and research material.

This architecture provides direct control over:

- Model selection
- Prompt execution
- API requests
- Experimental data
- Evidence collection
- Future AI Security testing

## Validation

The laboratory validated:

- Ollama installation and model execution
- Llama 3 availability
- Open WebUI connectivity
- Docker container operation
- Local API communication
- Persistent platform storage
- Reproducible environment deployment
