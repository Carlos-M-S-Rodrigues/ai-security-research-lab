# ADR-0001

## Title

Local-first AI Security Research Platform

## Status

Accepted

## Context

The objective of this project is to build a reproducible AI Security research platform capable of supporting future offensive and defensive AI laboratories.

## Decision

The platform will adopt a local-first architecture using Docker containers.

Every service will communicate through a dedicated Docker network.

Persistent data will be stored on an external SSD.

Docker Compose will orchestrate every service.

## Consequences

The platform becomes reproducible.

The environment becomes portable.

Future labs can reuse the same infrastructure.

Models remain persistent independently of containers.
