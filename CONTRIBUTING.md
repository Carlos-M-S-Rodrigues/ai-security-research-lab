# Contributing

Thank you for your interest in contributing.

This repository documents a personal AI Security learning journey, but constructive contributions are always welcome.

## Contributions

Examples include:

- Documentation improvements
- Typographical corrections
- New references
- Research suggestions
- Additional security resources

## Pull Requests

Please keep pull requests focused on a single topic.

Include a clear description of the proposed changes.

## Coding Standards

- Keep documentation written in Markdown.
- Follow existing folder structures.
- Maintain technical accuracy.
- Prefer reproducible experiments.

Thank you for helping improve this project.
